# Changelog

## 0.2.0

### Added

- Add torrents from magnet links and URLs, with save path, category, tags and "add stopped"
- Select torrents to start, stop, force start, recheck, reannounce or delete them, optionally with their files
- Queue position column and sorting, and moves to the top, up, down and to the bottom
- Details view with general information, files and trackers
- Open location, which opens a torrent's folder in a File Manager tab on a chosen Termix host, with an optional
  path mapping for containers
